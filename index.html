Metas de Orçamento
👥 Usuários & Permissões
Cadastre até 5 usuários para acesso pela rede. Cada um entra com nome + senha e aparece identificado no Histórico.
Editor = adiciona/remove · Leitor = só visualiza. Este PC (host) é sempre o dono.
🏢 Filiais
Cada filial tem seus próprios projetos, notas e análises (separados por CNPJ). Ao trocar de filial no menu, o app inteiro muda para os dados dela.
A filial ativa é global — quando alguém troca, todos passam a ver a mesma filial.
💾 Backup & Restauração
O app já faz backup diário automático. Aqui você pode exportar um backup agora, importar um arquivo, ou restaurar um dia anterior.
Restaurar/importar substitui todos os dados atuais (o estado atual vira dados.backup.json antes).
Backups diários automáticos
📥 Atualizar dados de compras
Exporte do seu sistema os dois relatórios de Entrada de Mercadoria do mesmo período e selecione abaixo. A app reprocessa Sugestões, Gastos e Preços automaticamente (já filtra os valores extremos).
📥 Importar planilha de projeto

Como cada planilha de projeto tem um formato, a importação é feita com o assistente (ele lê as colunas e cria o projeto certinho).

  1. Salve a planilha do projeto (.xls, .xlsx ou .csv) na pasta:
_importar/_projetos/
  1. Peça ao assistente: "importa os projetos da pasta".

Ele confirma o mapeamento das colunas com você e o Dashboard mostra a análise (previsto × real, economia, por categoria) automaticamente.
